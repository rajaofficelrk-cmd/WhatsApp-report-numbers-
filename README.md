# ⚡ Live Dashboard Control Panel

A simple, lightweight, offline-ready dashboard to track a live counter with
start / stop / reset controls, log export, and PWA support.

## 🚀 Features
- Paste report number from clipboard
- Live counter increments every second
- Duration timer (HH:MM:SS)
- Start / Stop / Reset controls
- Export log as `.txt`
- Auto-save inputs via localStorage
- Works offline (PWA + Service Worker)
- Keyboard shortcuts: `Enter` = Start, `Esc` = Stop
